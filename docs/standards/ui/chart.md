# UI 표준 — Chart / Graph

> 상태: **제안 (수락 대기)**

## 라이브러리

- **Recharts** 를 기본으로 한다(선언형·React 친화, shadcn/ui Charts 패턴과 동일).
  복잡한 대시보드 묶음이 필요하면 shadcn `ChartContainer`/`ChartTooltip` 래퍼를 함께 쓴다.
- 차트도 **CSS 변수 토큰으로 테마화**한다. 시리즈 색은 `--chart-1 … --chart-5` 를 정의해 사용.

```css
:root {
  --chart-1: 221.2 83.2% 53.3%;  /* 파랑  */
  --chart-2: 262 83% 58%;        /* 보라  */
  --chart-3: 160 60% 45%;        /* 청록  */
  --chart-4: 35 92% 55%;         /* 앰버  */
  --chart-5: 340 75% 55%;        /* 로즈  */
}
.dark {
  --chart-1: 217 91% 60%;
  --chart-2: 263 85% 70%;
  --chart-3: 160 65% 55%;
  --chart-4: 38 95% 62%;
  --chart-5: 340 80% 68%;
}
```

## 차트 종류 선택

| 종류 | 용도 |
|------|------|
| Line / Area | 시간에 따른 추세 |
| Bar (세로/가로) | 범주 간 비교 (가로 막대는 라벨 길 때) |
| Stacked Bar/Area | 구성 + 합계 추세 동시 |
| Pie / Donut | 구성비 — **범주 5개 이하**일 때만 (그 이상은 막대) |

## 예쁜 기본값 (pretty defaults)

- **여백**: `ResponsiveContainer` 로 가로 100%, 높이 고정(예: 260~320px). 차트 주변 패딩 확보.
- **그리드**: `CartesianGrid` 는 가로선만 옅게(`stroke=border`, `strokeDasharray="3 3"`), 세로선 제거.
- **축**: `axisLine={false} tickLine={false}`, 틱 글자는 `muted-foreground` 12px.
- **Area**: 선 + 하단 **그라데이션 채움**(시리즈색 0.3 → 0). 점(dot)은 기본 숨기고 hover시만.
- **Bar**: 모서리 둥글게 `radius={[6,6,0,0]}`, 막대 사이 간격 충분히(`barCategoryGap`).
- **Donut**: `innerRadius` 로 도넛, 가운데에 합계/핵심 수치 라벨.
- **툴팁**: 배경 `card`, 테두리 `border`, 반경 토큰, 그림자 약하게. 값은 천단위·단위 포함.
- **범례**: 항목 2개 이상이면 표시. 위치는 상단 또는 하단 일관.

## 규칙

- **색만으로 구분 금지**: 범례/직접 라벨 병행(접근성). 시리즈 순서는 `--chart-1`부터.
- **숫자 포맷**: 축·툴팁 모두 `toLocaleString` + 단위. 큰 수는 `1.2M`·`3.4천` 등 축약 허용.
- **상태**: 데이터 없음 → 빈 상태 문구, 로딩 → 스켈레톤/플레이스홀더, 에러 → 재시도 안내.
- **과밀 금지**: 한 차트에 시리즈 5개 초과 지양. 범주 많으면 가로 막대 + 스크롤/상위 N.
- 원시 색 직접 지정 금지 — `--chart-*` 토큰만 사용.
