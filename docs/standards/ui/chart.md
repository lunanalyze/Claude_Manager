# UI 표준 — Chart / Graph

> **룩앤필(격자·선 두께·채움·점 등 '분위기')은 [UI 표준 워크숍](./index.md)의 `chart` 선택이 정한다**
> (minimal/gridded/gradient/bold/soft). 이 문서는 그 위에서 **데이터에 맞는 차트 종류 선택**과
> 포맷·상태·접근성 같은 **사용 규칙**만 다룬다.

## 라이브러리

- **Recharts** 를 기본으로 한다(선언형·React 친화, shadcn/ui Charts 패턴과 동일).
  복잡한 대시보드 묶음이 필요하면 shadcn `ChartContainer`/`ChartTooltip` 래퍼를 함께 쓴다.
- 시리즈 색은 워크숍 테마가 정한 **`--chart-1 … --chart-5` 토큰**만 사용한다(원시 색 금지).

## 차트 종류 선택 (데이터 특성에 따라)

> 룩은 표준으로 고정하되, **어떤 그래프를 쓸지는 데이터가 결정한다.** 아래 기준으로 고른다.

| 종류 | 용도 |
|------|------|
| Line / Area | 시간에 따른 추세 |
| Bar (세로/가로) | 범주 간 비교 (가로 막대는 라벨이 길 때) |
| Stacked Bar/Area | 구성 + 합계 추세 동시 |
| Pie / Donut | 구성비 — **범주 5개 이하**일 때만 (그 이상은 막대) |
| Scatter | 두 변수의 상관·분포 |

## 규칙

- **색만으로 구분 금지**: 범례/직접 라벨 병행(접근성). 시리즈 순서는 `--chart-1`부터.
- **숫자 포맷**: 축·툴팁 모두 `toLocaleString` + 단위. 큰 수는 `1.2M`·`3.4천` 등 축약 허용.
- **여백**: `ResponsiveContainer` 로 가로 100%, 높이 고정(예: 260~320px). 주변 패딩 확보.
- **범례**: 항목 2개 이상이면 표시. 위치는 상단 또는 하단으로 일관.
- **상태**: 데이터 없음 → 빈 상태 문구, 로딩 → 스켈레톤/플레이스홀더, 에러 → 재시도 안내.
- **과밀 금지**: 한 차트에 시리즈 5개 초과 지양. 범주 많으면 가로 막대 + 스크롤/상위 N.
